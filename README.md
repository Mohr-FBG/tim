# Pronoun Party

Lernspiel zu den englischen **Subject Pronouns** (I, you, he, she, it, we, they) für Klasse 5. Es ist für das iPad gemacht und läuft direkt im Browser, ohne App.

## Spielmodi

| Modus | Inhalt |
|---|---|
| Lückensätze | 10 Sätze: Das passende Pronomen in die Lücke tippen oder ziehen. Bei Fehlern gibt es einen Tipp auf Deutsch. |
| Sortiermaschine | 12 Karten wie *my mum*, *the books* oder *Tom and I* in die richtige Pronomen-Box schieben. |
| Blitzrunde | So viele Sätze wie möglich in 60 Sekunden, ohne zweiten Versuch. |
| Fehlerjäger | Das falsche Pronomen im Satz finden und verbessern (auch kleines *i*). |
| Pronoun-Duell | Zwei Spieler an einem iPad, jeder auf seiner Bildschirmhälfte. Wer zuerst 7 Punkte hat, gewinnt. |

Dazu gibt es einen Spickzettel mit allen Pronomen und eine Fehlerauswertung am Ende jeder Runde.

## Nutzung

`index.html` in Safari öffnen. Über *Teilen → Zum Home-Bildschirm* lässt sich das Spiel wie eine App starten.
Mit aktivierten **GitHub Pages** (Settings → Pages → Branch `main`, Ordner `/root`) bekommt das Spiel eine feste Web-Adresse für die Klasse.

Bestwerte werden nur lokal auf dem jeweiligen Gerät gespeichert.
